# 💻 Portfólio — Vítor Maciel

Bem-vindo ao meu portfólio pessoal!

Este projeto foi desenvolvido para apresentar minha trajetória na área de tecnologia, minhas habilidades, conhecimentos e projetos desenvolvidos durante minha formação em **Sistemas de Informação**.

## 🚀 Sobre o projeto

O site funciona como uma apresentação profissional, reunindo informações sobre minha formação, tecnologias que estou estudando, projetos desenvolvidos e serviços que posso oferecer.

O objetivo é criar uma presença digital profissional e, ao mesmo tempo, demonstrar na prática meus conhecimentos em desenvolvimento web.

## ✨ Funcionalidades

* Design moderno e responsivo
* Navegação por seções
* Menu adaptado para dispositivos móveis
* Seção sobre mim
* Tecnologias e habilidades
* Projetos desenvolvidos
* Serviços
* Links para redes profissionais
* Contato via WhatsApp e e-mail
* Animações e efeitos de interação
* Layout adaptado para computador, tablet e celular

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Git
* GitHub

## 🎨 Seções do site

### 🏠 Início

Apresentação inicial com meu nome, área de atuação e uma breve descrição profissional.

### 👨‍💻 Sobre mim

Informações sobre minha formação, trajetória e objetivos profissionais.

### 🛠️ Habilidades

Apresentação das principais tecnologias e ferramentas que estudo e utilizo nos meus projetos.

### 🚀 Projetos

Área destinada aos projetos desenvolvidos, mostrando suas tecnologias, objetivos e links para visualização.

Apresentação de soluções que posso desenvolver para empresas e profissionais, como:

* Sistemas personalizados

Área para facilitar o contato através de WhatsApp, e-mail e redes profissionais.

## 🎯 Objetivos

Este projeto tem como principais objetivos:

* Desenvolver minhas habilidades em desenvolvimento web;
* Aplicar na prática conhecimentos adquiridos na graduação;
* Criar uma presença profissional na internet;

* Demonstrar minha evolução na área de tecnologia;

## 🔧 Como executar o projeto

Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

Entre na pasta:

```bash
cd SEU-REPOSITORIO
```

Depois, abra o arquivo:

```text
index.html
```

Você também pode utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.
